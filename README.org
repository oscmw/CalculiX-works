* About us
People contributing to this repo will mostly be affiliated with the loosely tied group of mechanicians entitled open-source computational mechanics and acoustics workshop, or OSCMW.

The "thread" called [[https://github.com/CalculiX-works/][CalculiX-works]] was created in order to share information, experience, knowledge as well as models created in [[https://dhondt.de][CalculiX]].

This document will be organized as blog sections (threads) devoted to specific problems  which will be found as issues (and branch names for that matter), in the github repo. For example, our first issue is related with the earing phenomenon in deep-drawing process. The second issue will be buckling, wind and earthquake response of the skirt of a vertical pressure vessel. Hopefully, there will be more topics (issues) to follow these...

The final section will be References where an enriched list of content addresses about CalculiX is aimed.

**** Post-Processing Notes
finding nodes that split holes into 2 equal parts on the horizontal axis at maximum stress locations using qenq in CalculiX CGX:
   1) display the stress dataset in cgx menu
   2) activate qenq   3) 
   3) Press m → enter max/min search mode
   4) Press r → click the first corner of a rectangle around the hole
   5) Press r → click the opposite corner
   6) Press h → CGX finds and labels the node with the maximum stress in that region
   7) Repeat with l (low) if you also need the minimum.
   8) Identify the horizontal-axis nodes (bisecting the hole)
   8.1) Press n while hovering over the node
       - CGX prints in the xterm:
       - Node number
       - Stress value at that node
       - XYZ coordinates (and cylindrical coordinates)
       - Which sets the node belongs to
   9) Press q to quit the qenq command
