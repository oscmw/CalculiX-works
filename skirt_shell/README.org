** Guide for File Names

*** gmsh_hlsX.py: Python script created for Gmsh API
*** gmsh_hlsX.med: med file obtained from Gmsh for Salome
*** salome_hlsX.med: file with thickened mesh
*** salome_hlsX.unv: unv file exported from Salome
*** salome_hlsX.inp: med/unv file created with meshio/unv2ccx

**** gmsh_hls13.py
surface orientation problems solved

**** gmsh_noholes12.py
script without boolean fragments

**** gmsh_hls6.py
script without mesh sizing

**** gmsh_hls13.med & gmsh_hls13.unv
without skir_carbo_und

**** gmsh_noholes12.med
without ovalop1_surf, ovalop2_surf, opening2_surf, manhole_surf

**** gmsh_hls6.med & gmsh_hls6.unv
file with full geometry

**** salome_hls13.inp
file created with unv2ccx

**** gmsh_hl6.inp
file created with Gmsh API
